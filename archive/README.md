# Archive

Nothing in this folder is run by the app. It is kept only as a record of how the project developed.

| Path | What it is |
|---|---|
| `legacy_modules/` | The original split-up version of the app. In version 8 these files were merged into one script, and later the core logic was split out again into `market_data.py`, `scorecard.py`, `llm_cost.py` and `snapshot.py` in the project root |
| `dev_scripts/` | One-off maintenance scripts used during development: a scan for names that shadow functions, a large patch script, and two refactoring helpers. Their file paths point at old locations and they are not meant to be run again |
